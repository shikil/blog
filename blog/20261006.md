# sed應用

---

sed是一個十分好用的command line text editor。例如要改code，

```
value="${bean.property}"
```

⇓

```
value="${fn:escape(bean.property)}"
```

就可以用sed，

```bash
sed -n -E 's/value="\$\{bean\.(.*)\}"/value="\$\{fn:escape\(bean\.\1\)\}"/p' a.jsp
```

sed -n 是只output match pattern的那行，先試試效果，-E 是採用extended regular expression。
單括號內的是regular expression，s解作substitution，基本形式是

```bash
's/search pattern/replace pattern/parameter'
```

今次要search pattern是value開頭包含bean的不同property，property並非hard code，所以在
符合search pattern後要放進replace pattern，用()，然後在replace pattern用\1取回，
最後的parameter是p，只print out。

當試過substitution沒有問題後，可以改sed parameter直接修改file，

```bash
sed -i -E 's/value="\$\{bean\.(.*)\}"/value="\$\{fn:escape\(bean\.\1\)\}"/' a.jsp
```

sed -i 是inplace edit。
