# pass好過keyring

---

[keyring](https://pypi.org/project/keyring/)是一個容易用但十分難config的package，
使用前需要先選擇backend作為password manager，
macOS相對簡單，用內置keychain作為backend便可以，
相反Linux有太多backend選擇，config困難。所以用command [pass](https://www.passwordstore.org/)

然後用`subprocess`，

```python
import subprocess

password = subprocess.run(["pass", f"{servicename}/{userid}"], stdout=subprocess.PIPE).stdout.decode("utf-8").strip()
```
