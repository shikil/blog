# AI讀PDF(上)

---

一世人流流長實儲埋好多PDF，如月結單糧單稅單等等，但PDF並非有效
data format，要從當中給AI讀到有用資訊，只需寫幾行Python便可。

1. 安裝[uv](https://docs.astral.sh/uv/)，uv集Python version管理,
package管理和解決package dependence於一身。
1. 開一個新directory，然後`uv init`
1. [pymupdf](https://github.com/pymupdf/pymupdf)是從PDF讀取文字的Python package，暫時未支援Python 3.15，
所以要先行`uv python pin 3.14`， 然後行`uv add pymupdf`便可。
1. 以下例子是讀PDF然後以markdown形式輸出。

    ```python
    import pymupdf
    doc = pymupdf.open("abc.pdf")
    doc.to_markdown()
    ```

1. 而我們需要每版抽取文字處理，所以用

    ```python
    for i, page in enumerate(doc.pages()):
        text = page.get_text()
    ```

1. 將文字每1000字分批處理，

    ```python
        for j in range(0, len(text), 1000):
            chucks.append(text[j:j+1000])
            metadatas.append({"filename":name, "page": i})
    ```

1. 抽取到文字出來後，將文字放入vector database儲存以便model存取。最普遍使用
的vector database是[chroma](https://www.trychroma.com/)，只要`uv add chromadb`
1. chroma最基本用法是儲存local，指明位置再指明collection name，collection name類似
普通database的schema，如下

    ```python
    import chromadb
    client = chromadb.PersistentClient("abc")
    collection = client.create_collection(name="abc")
    ```

1. 便會有一個subdirectory abc，將準備好的chucks和metadata加入到collection當中。
1. 完整program如下：

```python
import pathlib
import sys

import chromadb
import pymupdf

if len(sys.argv) != 3:
    sys.exit()
doc = pymupdf.open(sys.argv[1])
chucks = []
metadatas = []
name = pathlib.Path(sys.argv[1]).name
for i, page in enumerate(doc.pages()):
    text = page.get_text()
    for j in range(0, len(text), 1000):
        chucks.append(text[j:j+1000])
        metadatas.append({"filename":name, "page": i+1})

client = chromadb.PersistentClient(sys.argv[2])
collection = client.get_or_create_collection(name="documents")
collection.add(ids=[f"{name}::{i}" for i in range(len(chucks))],
               documents=chucks,
               metadatas=metadatas)
```
